# Rupam Precision Website

This is a modern, high-performance static website for Rupam Precision built with Astro, TypeScript, Tailwind CSS, and GSAP. 

## Project Setup
- Framework: Astro
- Styling: Tailwind CSS
- Animations: GSAP (with ScrollTrigger)

## Commands
- `npm run dev`: Start dev server
- `npm run build`: Build for production

See `design-brief.md`, `content-TODO.md`, and `route-checklist.md` for project specifications.
